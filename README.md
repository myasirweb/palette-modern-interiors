# Palette — Interior Designer Website

A modern, fully responsive interior design portfolio website built with **Next.js 15** and **Sass**.

## Tech Stack

- [Next.js 15](https://nextjs.org/) (Turbopack)
- React 18
- Sass / SCSS
- Swiper.js
- WOW.js
- Isotope Layout

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm start
```

Compile SCSS manually (optional — runs automatically in dev):

```bash
npm run sass
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
palette/
├── app/              # Next.js App Router pages
├── components/       # Reusable UI components
│   └── layout/       # Header, Footer, MobileMenu
├── public/           # Static assets (images, css, scss)
└── package.json
```
